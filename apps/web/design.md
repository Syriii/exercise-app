# 正式 Web：手机优先界面

2026-10-28。延续已认可的 mobile-redesign 原型，不更换 Vue 技术栈。产品范围、领域行为仍以 docs/product.md 和 docs/domain/domain-rules.md 为准。

## 视觉与页面

暖白底、绿色主操作、中文系统字体、统一线性图标。14px 辅助文字、16px 正文、20px 区块标题、28px 页面标题；按钮至少 44px。手机底部五项导航，桌面侧栏；主体与导航分区滚动，不遮挡最后一项。令牌及覆盖样式位于 src/styles/mobile-redesign.css，原有全局样式保留。

- 今天：能量主数值与三项营养，拍照入口、上一餐；训练参考与实际记录，身体提醒仍按用户设置出现。
- 饮食：当天营养、拍照／相册、手动辅助；入口直接打开对应系统选择器，取消不建餐。餐食用真实上传照片或明确标识的类别插图，删除整餐在餐食操作菜单。打开餐食聚焦核对，当前原图、保存状态与不确定说明先呈现；改份量和换食物可直接进入，名称/已知营养修正位于对应食物旁。替换编辑器独立于目标行生命周期，服务器移除目标后仍保留选择和恢复提示。
- 手动添加：先选食物、改份量，再保存。收起不建立空餐。常用优先，分类覆盖完整目录；来源、生熟及加工差异不因简化显示而丢失。
- 无搜索词时，常用之后优先展示已有目录中的日常食物；搜索精确名称优先。已选份量放在结果列表之前，不要求穿过完整列表才能修改。展示层能量取整、三大营养素最多一位小数，底层保存和换算精度保持。
- 训练：保留看／改计划与事后记录两条链，不引入边练边计数。已有动作指导、修订、复用、计划关联和回顾仍可用。
- 训练记录直接选择自选/当天计划/已有计划/上次实际内容；动作可连续多选后集中核对。实际有氧记录默认分钟/公里，可切换秒/米，底层保持秒/米；已有非整分钟时长保持秒，距离小数不丢失。计划来源仍默认未勾选，不能把参考量当完成事实。
- 历史：按日记录与趋势；体重点位来自实际测量，横轴按日期间距，连线不是未测日期的估算。
- 我的：身体数据优先，资料、目标和应用设置分开；识别授权默认不选，在注册时提供，已有账号在应用设置管理。

## 实现与恢复边界

### 全页面交互层级

列表只承担识别和选择：标题、关键数值、状态及一个进入入口。计划列表先显示我的计划；生成草案、多周编排、仅安排主题放在次要入口。展开计划才显示动作目标和安排/记录，编辑/复制/归档进一步收纳。新建、编辑和日期安排不与列表挤在同一屏。

已选动作使用名称与短数量行，改名、逐组差异、排序、说明按需展开。目标范围与时长/距离仍可编辑，空值不补零或捏造推荐量。身体记录默认日期和体重，腰围/备注按需；首次设置的安全适用边界保持显式。历史用图标标识记录类型，趋势方法解释按需；账号删除表单折叠但展开后完整展示后果。错误、恢复和授权提示不按“减少文字”隐藏。

训练的密集内容：摘要保留总数、最多三个动作名称，名称最多两行；全量内容在展开后显示。选择有氧动作时，新目标表单直接展示时长／距离两列；力量动作仍为三列。已有目标及用户手动切换优先，不自动填写、不改变进度依据。记录选入动作后焦点落到动作标题，不强制唤起输入键盘。计划编辑保存栏在内容滚动区底部保持可达，不覆盖底部导航；清空次数上限不自动收起正在编辑的字段。

覆盖所有正式路由及设置子页；320/375/414/768 和桌面验证。减少可见内容不能损失功能、未知状态或使重要操作只能靠无标签图标猜测。

首次设置：出生日期与活动量使用整行，性别与身高并列；健康情况用短标签显式展示。未知体重选项与测量输入互斥显示且不丢未提交输入，步骤操作栏保持可达。进度读取失败使用独立重试状态，不展示新用户表单或清空已填资料；重试成功再分流。

记餐与训练共同采用“先选内容，再改数值”：默认界面展示食物／动作列表，不将名称、备注和详细修正排在主内容前。日期时间用紧凑摘要按需修改，搜索保持整行，份量／组数／次数／重量使用短控件；触摸区域仍不少于44px。分类可直接点选，保存入口与已选数量相邻。训练参考内容只有经用户勾选并核对后才计入本次，未知量保持未知。

MealPhotoPicker 是 Web 选图边界：拍照输入使用 capture，相册输入不使用 capture；取消选图保留已有附件。对象 URL 随附件更换／组件卸载回收。Android 后续可替换该边界，但尚未接入原生相机、Photo Picker 或系统返回；浏览器模拟不等于安卓真机验收。

今天入口在用户手势内打开相机，选图后经账号作用域内存交给同一记餐流程，不进入URL、history state或浏览器持久存储。旧草稿存在时先显示新旧入口分流，取消新照片保留旧稿，放弃旧稿须明确确认；照片准备串行，新选文件在能够接入前不消费。实际切日重置后的迟到选图不会恢复已放弃的照片，普通切页仍保留草稿。自动计入成功不再展示“使用结果”，新识别结果仍保留预览/替换/撤销。“识别详情”只展开识别历史与管理，核对原图独立保留。

食物保存沿用服务端原有幂等提交编号。新餐食与食物仍是两个已有 API 请求：建立成功、食物失败时复用餐食；建立响应未知时停止重复创建并要求核对列表，可显式选中已建立餐食继续。不是新增的跨请求原子事务。

照片和业务数据只使用本账号已有 API；不引入第三方图片请求、模型调用或新表。类别插图不代表食材实拍，未经验证的精细品种不合并为营养完全相同的食物。

注册成功、识别设置失败时保持登录状态并单独重试设置，不重复注册；也可关闭自动识别继续。识别授权不是系统相机／相册授权。

## 验收范围

覆盖完整手机／桌面交互、320/375/414/768/960/1440 排版、相册入口的 capture 属性、选图取消、注册授权与失败恢复、手动选择取消及保存重试、餐食删除。真实 Android 相册、系统返回、软键盘、低内存重启和安装包仍需后续真机阶段，不以 Web 测试冒充。
