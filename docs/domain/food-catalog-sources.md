# 食物目录数据来源与实现边界

更新：2026-09-07。记录 B1 的来源和实现选择；产品行为以 product.md、domain-rules.md 为准，是否已验收/上线以当前计划为准。

## 普通食物起始子集

使用 USDA FoodData Central 的 **SR Legacy 2018-04** 官方 CSV 下载包，当前选择16种食物作为可扩充的起始覆盖。不是全球食物全集，也不是中国食物成分表或食堂菜品的实测值。中文名称保留原记录的生熟、烹调、强化和乳脂等区分，英文原名可以在来源详情核对。豆奶记录不冒称为中国无糖现磨豆浆。

- [官方数据下载](https://fdc.nal.usda.gov/download-datasets/)；[SR Legacy 数据类型说明](https://fdc.nal.usda.gov/data-documentation/)。此版本为历史固定版，不声称是所有数据类型的最新版本。
- [官方许可说明](https://fdc.nal.usda.gov/api-guide/#licensing)：FoodData Central 数据为公共领域、CC0 1.0，保留 USDA/FoodData Central 归属。
- 下载包：`FoodData_Central_sr_legacy_food_csv_2018-04.zip`；SHA256：`b80817294b8850530aaedf2e515c02593b1824f763a0ff356e5c2081643e6fd0`。
- 可复现生成器：`apps/server/scripts/generate-food-catalog.py`；输入为官方原始 ZIP，输出 `apps/server/src/modules/nutrition/usda-foods.generated.ts`，不联网、不读取用户数据。源包仅存临时目录，不提交。
- 食物使用稳定 FDC ID；每100 g的能量、蛋白质、总脂肪、差减法碳水分别取 nutrient ID 1008、1003、1004、1005。缺失字段保留 null，不用其他能量字段、单位换算或模型记忆填补。
- 当前仅提供克数基准，未自行假定一碗、一杯、一个的固定克数，也不将克与毫升互换。来源细节与基准随餐食快照保存。

E-011 中国食物查询平台仍未取得整库再分发授权，不抓取或导入其数据库。本次使用许可兼容替代来源，不更改其科学证据优先级。

## 包装食品与个人食物

Open Food Facts 仍是按用户明确搜索临时接入的来源，沿用技术架构6.4的超时、缓存、限流和许可边界。普通、个人、包装食品合并到一个结果列表；空查询只浏览全部已接入的普通食物与该账号保存的个人条目/常用来源快照，不声称已下载 OFF 整库。

未取得可靠类别的外部或历史条目列入“其他食物”，不凭名称强行分类或跨来源合并。用户补充个人食物可指定整体分类。外部结果保留品牌、条码身份、来源与 ODbL/DbCL 归属；选中外部数据不是经过实测确认。

API 内对最近返回的公共结果保留最多1000项、10分钟的内存解析缓存，供提交时从服务端解析真实来源与营养；不接受客户端伪造权威营养或来源。缓存丢失时未保存的外部条目需重新搜索，已选草稿不清空。个人常用的来源快照存于原有账号私有表；旧个人食物不按同名去重。

## 快照、保存与兼容

- 常用标记不修改公共营养、不增加目录重复项、不改变食物营养版本。取消常用不删除餐食或个人食物。
- 食物选择每批最多20项，服务端按基准计算实际量，整批在同一事务中加入餐食。稳定提交编号派生贡献项ID；重复提交不重复新增，修改或删除后的旧重试不得恢复原条目。
- 新条目保存身份、版本、分类、来源、基准及四项营养快照；改份量使用该快照重新换算，避免连续缩放舍入漂移。营养手动纠错会解除旧计算基准，旧快照仍在修订记录中。
- 0021/0022迁移仅在原有3张表增加6个字段与1个私有唯一索引，无新表、无删除或按名称合并历史数据。批次编号用于拒绝“同一提交编号却删掉部分选择”的伪重试。沿用现有RLS、账号删除级联、导出中的私有表范围。
- UI旧饮食安排、全天确认、个人模板管理的完整收敛，以及识别开关/恢复仍需后续B切片；不能把B1目录能力等同于U05全部完成。
